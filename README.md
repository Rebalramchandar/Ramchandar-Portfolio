# Pitla Ramchandar — Geospatial Portfolio

Responsive, single-page personal portfolio for GIS, Remote Sensing and Geospatial Data Analysis.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive premium dark theme, custom CSS artwork and motion
- `script.js` — scroll reveal and mobile navigation
- `assets/` — place reviewed public portfolio images here

## Preview
Open `index.html` in a modern browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a new public repository for the portfolio.
2. Upload the website files (do not upload original restricted NRSC source data).
3. In repository Settings → Pages, choose Deploy from a branch, `main`, and `/ (root)`.
4. Add your purchased custom domain in Pages settings and configure the DNS records GitHub provides.

## Lovable
Connect the Lovable app to ChatGPT, then import this project or use these files as the basis for a Lovable project. Review the content and design before publishing.

## Pre-publication checklist
- Confirm that the phone number and email are suitable for public display.
- Add a professional portrait if desired.
- Replace the schematic map graphic with an approved, publication-safe SST map or plot.
- Add a final CV PDF only after placing the file in this project and linking it.
- Update MSc result status after official declaration.
- Do not upload raw/restricted satellite granules, raw buoy source files, credentials, private correspondence or confidential material.
